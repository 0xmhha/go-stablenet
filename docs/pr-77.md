[StableNet] 거버넌스 GasTip 복원 제안 시 트랜잭션 Pending Pool 정체 이슈 원인 분석

## 설명

## 배경
- StableNet에서는 거버넌스를 통해 gasTip 값을 동적으로 변경할 수 있음.
- 기본값은 27600 Gwei이며, 거버넌스(GovValidator) 제안을 통해 변경 가능함.

## 현상
- 다음 시나리오에서 트랜잭션이 처리되지 않는 문제가 발생함:

### 재현 시나리오
1. 초기 상태: gasTip = 27600 Gwei
2. 거버넌스 제안 → 30000 Gwei로 변경 (정상 반영)
3. 이후 27600 Gwei로 복원하기 위한 거버넌스 제안 트랜잭션 제출

### 결과
1. 해당 트랜잭션이 pending pool에 지속적으로 남아 있음
2. 블록에 포함되지 않으며 상태 변화 없음
3. 동일 조건에서 반복 재현 가능

## 통과 기준 유닛테스트 (수정 완료 시 반드시 통과)
- gasTip 이 변경된 이후, 변경된 gasTip 의 조건에 부합하지 않는 트랜잭션은 pending pool 에 남아있지 않아야 한다. 

### 통과 조건
- 위 핵심 케이스는 수정 전 코드에서는 실패해야 한다(회귀 검출력).
- go test -race "수정 테스트 코드가 반영된 테스트 파일" -> 통과.

### 시뮬레이션 테스트 코드
